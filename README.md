# Cull

**Cull** is a fast burst-culling app for Nikon NEF (RAW) photos, built with Tauri, Rust, and React.

This repository hosts the **public release binaries** for the app. The source code is maintained privately.

## Downloads

Grab the latest build from the [**Releases**](https://github.com/manishprivet/cull/releases) page.

## Installation

Download the installer for your platform from the latest release and run it.

- **Windows** — `.msi` or `.exe` installer
- **macOS** — `.dmg`
- **Linux** — `.AppImage` or `.deb`
